01 // About

Quality isn't a phase. It's built in.

I'm a QA Automation Engineer / SDET based in Noida, India, with 4.5+ years of experience in functional and automation testing. I specialize in designing scalable Playwright automation frameworks in JavaScript using the Page Object Model, reusable fixtures, and data-driven testing, covering Functional, Regression, Smoke, Sanity, Integration, End-to-End (E2E), and User Acceptance Testing (UAT).

A core part of my work is AI-based quality testing for AWS media/OTT platforms — validating AI-driven features like content moderation, video semantic search, intelligent thumbnail generation, and metadata enrichment (built on Rekognition, Bedrock, and Transcribe), alongside the underlying S3, MediaConvert, MediaLive, and AWS IVS pipelines. I've automated 50%+ of regression coverage across my teams, integrated suites into GitHub Actions and Jenkins with Allure reporting, and mentor junior QA engineers while partnering with developers and product managers to shift quality left.
